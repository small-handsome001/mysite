## 二、数据的形状（先看懂再动手）

`assets/notes.json`：

```json
[
  {
    "date": "2026-10-18",
    "title": "服务器说「接受你的钥匙」，然后拒绝了我",
    "url": "notes/ssh-key.html"
  }
]
```

三对键值：`date`（日期）、`title`（标题）、`url`（文章链接）。

**和 music.json 比的差别：**

- `music.json` 里 `file` 是音频文件，`notes.json` 里 `url` 是**另一个网页**
- 别的都一样：都是数组，数组里都是对象

## 三、三个 TODO，按顺序来

打开 `D:\my-site\notes.js`，你会看到三个 TODO。

### TODO 1：把每条笔记变成一段 `<li>`

原来手写的结构是：

```html
<li>
  <span class="note-date">2026-10-18</span>
  <a href="notes/ssh-key.html">服务器说「接受你的钥匙」，然后拒绝了我</a>
</li>
```

你要在 `map` 里用模板字符串生成它，把写死的日期/标题/链接换成 `${note.date}`、`${note.title}`、`${note.url}`。

### TODO 2：外层 `<ul class="note-list">` 也要拼

页面里的 `#note-list` 现在是个空 div。**`<ul>` 标签在原来的 HTML 里被你删掉了**，所以它必须由 JS 生成：

```
起始：<ul class="note-list">
中间：3 段 <li>
结尾：</ul>
```

### TODO 3：塞进页面

```js
listEl.innerHTML = 上面拼好的字符串;
```

## 五、这一步的意义

加一篇新笔记，从今往后只有三步：

```
1. 写文章 pages → notes/新文章.html
2. 在 assets/notes.json 加一个对象
3. git push
```

**不用再碰 `notes.html`。** 你在第 12 课抽掉了页头页脚，这一课抽掉了内容——你的站从此是「数据 + 模板」，不是「手抄七份」。

## 六、卡住时看这三个地方

| 现象 | 查哪里 |
|---|---|
| 列表空 | Console 红字 → `note` 拼错 / 少 `return` |
| 出现 `[object Object]` | 模板里写了 `${note}` 而不是 `${note.title}` |
| 链接 404 | `url` 是相对 `notes.html`（根目录）的路径，`notes/xxx.html` |
| 日期和标题挤在一起 | 忘了 `<span class="note-date">` 这层壳 |
