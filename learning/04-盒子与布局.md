# 第 4 课 · 盒子模型与 Flexbox

## 一、每个元素都是盒子

```
┌──────────────────────────┐
│        margin 外边距      │  ← 和"别人"的距离
│  ┌────────────────────┐  │
│  │    border 边框      │  │  ← 那条可见的线
│  │  ┌──────────────┐  │  │
│  │  │ padding 内边距│  │  │  ← 边框到内容的距离
│  │  │ ┌──────────┐ │  │  │
│  │  │ │ content  │ │  │  │  ← 文字/图片
│  │  │ └──────────┘ │  │  │
│  │  └──────────────┘  │  │
│  └────────────────────┘  │
└──────────────────────────┘
```

`background-color` 铺满 content + padding + border，**不包括 margin**。

| 想干什么 | 用 |
|---|---|
| 盒子和外面拉开距离 | `margin` |
| 盒子和内部内容拉开距离 | `padding` |
| 卡片之间有空隙 | `margin`（或父元素 `gap`） |
| 卡片里文字不贴边 | `padding` |

**`padding` 是里，`margin` 是外。**

> ⚠️ margin 会**塌陷**：上下相邻时取大的，不是相加。`h2` 的 `margin-top:40px` 遇到 `p` 的 `margin-bottom:16px`，最终是 40px。

## 二、box-sizing：为什么第一行永远是它

```css
.box { width: 300px; padding: 20px; border: 5px solid red; }
```

**实际占 350px，不是 300px。** 浏览器默认把 `width` 只算 content 层，padding 和 border 往外加。

```css
* { box-sizing: border-box; }
```

改成"`width` 指整个盒子，padding 和 border 往里挤"。`*` = 所有元素。

**这就是 CSS 第一行的由来。**

## 三、Flexbox

元素默认竖着堆（`div` 是块级元素）。要横排：

```css
.container {
  display: flex;                  /* 加在"父元素"上 */
  justify-content: space-between; /* 横向分布 */
  align-items: center;            /* 纵向对齐 */
  gap: 20px;                      /* 子元素之间空隙 */
}
```

| 属性 | 管什么 | 常用值 |
|---|---|---|
| `justify-content` | 横向 | `flex-start` / `center` / `space-between` |
| `align-items` | 纵向 | `flex-start` / `center` / `stretch` |
| `gap` | 子元素间距 | `20px` |

**`display: flex` 写在父元素上，不是子元素上。** 这是最容易错的地方。

### `flex: 1` 和 `flex: 0 0 96px`

```css
.card { flex: 1; }            /* 平分剩余空间：能放大、能缩小 */
.date { flex: 0 0 96px; }     /* 固定宽度：不放大、不缩小、96px */
```

`flex: 1` = `flex: 1 1 0`。三个值是 grow / shrink / basis。

## 四、坑

| 现象 | 原因 |
|---|---|
| `display: flex` 没用 | 加在子元素了，要加在父元素 |
| 卡片被压扁 | 内容太多，加 `flex-wrap: wrap` 或 `min-width` |
| 加 padding 撑破 | `box-sizing` 没设 `border-box` |
| `justify-content` 没反应 | 忘了先写 `display: flex` |
| 宽度不等 | 没加 `flex: 1` |
| **注释漏了 `*/`** | 会吞掉后面一行代码，且不报错。**用脚本数 `/*` 和 `*/` 数量** |

## 五、验证

F12 → Elements → 点元素 → 右下角**盒模型图**，悬停每一层页面会高亮。这是记住盒子模型最快的方式。
