# 第 2 课 · HTML：给内容加结构

## 一、标签

```html
<h1>张三</h1>
```

`<h1>` 开始标签 / `张三` 内容 / `</h1>` 结束标签。
`h1` = heading level 1。你只说"这是标题"，**多大字号是浏览器的默认决定**。

常用标签：`<h1>`~`<h6>` 标题、`<p>` 段落、`<a>` 链接、`<img>` 图片、
`<ul>`/`<ol>` 列表、`<li>` 列表项、`<div>` 分块、`<span>` 行内片段。

## 二、嵌套两条铁律

1. **先开的后关**：`<p><strong>字</strong></p>` ✅ ；`<p><strong>字</p></strong>` ❌
2. **内层缩进两个空格**（浏览器不在乎，但你在乎——50 行后你会分不清谁关谁）

VSCode 自动格式化：`Shift + Alt + F`

## 三、属性

```html
<a href="projects.html">我的项目</a>
```

格式永远是 `名字="值"`，等于 Python 的关键字参数。

常用：`href`（链接）、`src`（资源）、`alt`（替代文字）、`class`（类名）、`id`（唯一标识）。

## 四、最小结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>页面标题</title>
</head>
<body>
  ...用户能看到的都在这
</body>
</html>
```

**`<head>` 是说明书（给浏览器看），`<body>` 是正文（给用户看）。**

## 五、坑速查

| 现象 | 原因 |
|---|---|
| 中文乱码 | `meta charset` 没写 |
| 页面一半没显示 | 有标签没关，后面被吞进去了 |
| 链接点了没反应 | `href` 拼成 `herf` / 忘引号 |
| 改了没变化 | **Ctrl + S 保存了吗** |
| 中文引号 | 输入法中文状态打的 `"`，浏览器不认 |
