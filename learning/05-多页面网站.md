# 第 5 课 · 做出一个真正的网站

## 一、网页 vs 网站

网站 = **多个页面 + 把它们串起来的链接**。

`<a href="projects.html">` 不只是"跳转"，它把散落的页面变成一个整体。

## 二、页面间链接（路径）

同一个文件夹里，直接写文件名：

```html
<a href="projects.html">项目</a>
```

子文件夹用 `/`，上一级用 `../`：

```html
<a href="pages/projects.html">项目</a>   <!-- 往下走 -->
<a href="../index.html">回首页</a>        <!-- 往上走，和 Python 的 .. 一样 -->
```

## 三、模板：每个页面都一样的地方

```html
<header class="site-header">
  <div class="logo">yorin</div>
  <nav class="nav">
    <a href="index.html">首页</a>
    <a href="projects.html">项目</a>
    <a href="notes.html">笔记</a>
  </nav>
</header>

<main class="wrap">
  <!-- 只有这块每个页面不一样 -->
</main>

<footer class="site-footer">
  <p>© 2025 yorin</p>
</footer>
```

页头页脚复制三份，只有 `<main>` 不同。**这就是"模板"概念**，以后学框架就是自动化这件事。

现在接受这个"复制"，因为没有 JS 和构建工具之前没法消除它。**先能跑，再优化。**

## 四、标准 `<head>`

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>页面标题</title>
  <link rel="stylesheet" href="site.css" />
</head>
```

`viewport` 那行让页面宽度等于手机屏幕宽度，不然手机上会缩得很小。

## 五、本课新知识

| 新东西 | 意思 |
|---|---|
| `<main>` | 页面主体内容 |
| `<header>` `<footer>` `<nav>` | 页头 / 页脚 / 导航，语义比 `<div>` 明确 |
| `<article>` | 一篇独立内容（一个项目、一条笔记） |
| `../` | 路径里的上一级目录 |
| `vh` / `vw` | 视口高度/宽度的百分比，`60vh` = 窗口高的 60% |
| 一份 CSS 多页共用 | 改一处，所有页面同时变 |

## 六、验收

- [ ] 三个页面顶部导航完全一样，能来回跳
- [ ] 三个页面共用同一个 `site.css`（改一次三页同时变）
- [ ] F12 → Network 里 `site.css` 只加载一次
- [ ] 页脚在每页底部，样式一致
- [ ] 不用手输地址，全靠导航点击
