## filter 是什么

和 `map` 是兄弟，都用在数组上：

| 方法 | 干什么 | 返回什么 |
|---|---|---|
| `map` | 每一项都变一次 | 新数组（**数量不变**） |
| `filter` | 只留下符合条件的 | 新数组（**数量变少**） |

```js
const cssNotes = notes.filter(function (note) {
  return note.tags[0] === "CSS";   // true 的留下，false 的扔掉
});
```

`return` 后面那个表达式，就是「判断条件」。真留下，假扔掉。

对照 Python：`[n for n in notes if n["tags"][0] == "CSS"]`

## 四步，每步都能刷新看到结果

### 第 1 步：把「渲染」抽成函数

现在你的渲染代码是写死在 `.then` 里的。要能反复调用，必须先包成函数。

```js
function renderNotes(list) {
  const items = list.map(function (note) {
    return `
      <li>
        <span class="note-date">${note.date}</span>
        <a href="${note.url}">${note.title}</a>
        <span class="note-tag">${note.tags[0]}</span>
      </li>
    `;
  }).join("");

  listEl.innerHTML = `<ul class="note-list">${items}</ul>`;
}
```

然后把 `.then` 里原来那几行换成一句：

```js
.then(function (notes) {
  renderNotes(notes);   // 第一次：全部显示
})
```

**刷新**：页面和现在一模一样。**说明你没改坏。**

### 第 2 步：造出「全部 / CSS / SSH / HTML」这几个按钮

思路：从数据里把标签**收集起来**，拼成按钮。

```js
.then(function (notes) {
  // 1. 收集所有标签（每条笔记都有 tags[0]）
  const tags = notes.map(function (note) {
    return note.tags[0];
  });
  // 到这里 tags = ["SSH", "CSS", "HTML"]

  // 2. 前面补一个「全部」
  const allTags = ["全部"].concat(tags);
  // allTags = ["全部", "SSH", "CSS", "HTML"]

  // 3. 每个标签变成一个按钮，拼成 HTML
  const buttons = allTags.map(function (tag) {
    return `<button class="filter-btn" data-tag="${tag}">${tag}</button>`;
  }).join("");

  filterEl.innerHTML = `<div class="filter-bar">${buttons}</div>`;

  renderNotes(notes);
})
```

同时在文件顶部加一行：

```js
const filterEl = document.querySelector("#note-filter");
```

**刷新**：标题下面出现 4 个胶囊按钮。

> `data-tag` 是**自定义属性**。它不是给用户看的，是给 JS 读的——点按钮时用它判断「你点的是哪个标签」。

---

### 第 3 步：点击时筛选

```js
.then(function (notes) {
  // ... 上面造按钮的代码 ...

  // 给整个筛选区挂一个监听（不用给每个按钮单独挂）
  filterEl.addEventListener("click", function (event) {
    const tag = event.target.dataset.tag;
    if (!tag) return;              // 点到按钮之间的空隙就退出

    const filtered = tag === "全部"
      ? notes                      // 三元表达式：全部就是不过滤
      : notes.filter(function (note) {
          return note.tags[0] === tag;
        });

    renderNotes(filtered);
  });
})
```

**刷新后点按钮**：列表会变。

### 第 4 步：让「当前选中的按钮」变黑

现在点完没提示，用户不知道选了什么。补一句高亮：

```js
filterEl.addEventListener("click", function (event) {
  const tag = event.target.dataset.tag;
  if (!tag) return;

  // 先把所有按钮的高亮去掉，再给被点的那个加上
  const btns = filterEl.querySelectorAll(".filter-btn");
  btns.forEach(function (btn) {
    btn.classList.remove("is-active");
  });
  event.target.classList.add("is-active");

  // ...下面是第 3 步的筛选代码...
});
```

> `querySelectorAll` 返回的**不是数组**，但可以直接 `.forEach`。
> 这是它和 `querySelector` 的区别，也是第 6 课纠过的那个「只接受一个参数」。

**加分**：页面刚打开时，「全部」按钮应该是黑的。

提示：造完按钮后，手动给第一个按钮加 `is-active`。可以在拼字符串时判断，也可以 `filterEl.querySelector(".filter-btn").classList.add("is-active")`。

## 一句提醒

第 2 步里 `const allTags = ["全部"].concat(tags);` 的 `concat` 是「把两个数组接起来」。

你也可以写成 `["全部", ...tags]`（`...` 叫展开运算符），效果一样。以后在别人的代码里会常见到，先认个脸。
