# 第 7 课 · 把网站变成真的

前 6 课你都在"练习题"里打转。这一课开始，**你的网站是真的**。

## 这一课要拿到什么

1. 三个页面填上**你自己的内容**
2. 新增一个**音乐页**，能点开听你的曲子

## 一、文件命名规范（先定规矩）

现在开始，所有文件都用这套规则：

| 类型 | 规则 | 例子 |
|---|---|---|
| 文件名 | 小写英文 + 连字符 | `music.html`、`track-01.mp3` |
| 不能有 | 空格、中文、括号 | ❌ `my song(1).mp3` |
| 图片 | 放 `assets/img/` | `assets/img/avatar.jpg` |
| 音频 | 放 `assets/audio/` | `assets/audio/track-01.mp3` |

**为什么？** 中文文件名在网页里要转成 `%E4%B8%AD%E6%96%87` 这种编码，一旦服务器或部署平台编码处理不一致，链接就断。这是最常见的"本地好好的，传上去 404"的原因。

`assets/` 两个文件夹我已经建好了。

## 二、音频：`<audio>` 标签

```html
<audio controls src="assets/audio/track-01.mp3"></audio>
```

| 属性 | 作用 |
|---|---|
| `controls` | 显示播放/进度条/音量。**不加就是隐形的**，什么都看不到 |
| `src` | 音频文件路径，写法规则和 `<link href>`、`<img src>` 完全一样 |

### 格式问题（重要）

| 格式 | 浏览器支持 |
|---|---|
| **MP3** | 全部支持 ✅ 最保险 |
| **M4A / AAC** | 全部支持 ✅ |
| FLAC | Chrome / Edge / Firefox 支持；**Safari 不支持** ⚠️ |
| WAV | 支持但文件巨大，不适合放网页 ❌ |

**结论：放到网上的曲子，导出成 MP3（128~192kbps）。** 你的 FLAC 母带自己留着。

### 兼容写法（可选）

想同时提供两种格式，用 `<source>`：

```html
<audio controls>
  <source src="assets/audio/track-01.mp3" type="audio/mpeg" />
  <source src="assets/audio/track-01.flac" type="audio/flac" />
  你的浏览器不支持音频播放。
</audio>
```

浏览器按顺序挑第一个能播的。最后那行文字是"都播不了时的提示"。

## 三、图片：`<img>`

```html
<img src="assets/img/avatar.jpg" alt="幽林的头像" />
```

**`alt` 不能省。** 它是图片加载失败时显示的文字，也是给读屏软件用的。写"图片"、"头像"这种没意义的词等于没写——要写"这张图是什么"。

控制大小（宽度按比例缩）：

```css
img.avatar {
  width: 120px;
  border-radius: 50%;
}
```

`<img>` 只需要设 `width`，高度会自动等比缩放，不会变形。

## 四、新建音乐页

新建文件 `learning/site/music.html`，把下面这段敲进去（**不要复制粘贴，敲**）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>幽林 | 音乐</title>
  <link rel="stylesheet" href="site.css" />
</head>
<body>

  <header class="site-header">
    <div class="logo">幽林</div>
    <nav class="nav">
      <a href="index.html">首页</a>
      <a href="projects.html">项目</a>
      <a href="music.html">音乐</a>
      <a href="notes.html">笔记</a>
    </nav>
  </header>

  <main class="wrap">

    <h1>音乐</h1>
    <p class="intro">原创曲目和编曲练习。点播放。</p>

    <div class="track">
      <h3>曲名一</h3>
      <p class="meta">2026 · MIDI 编曲</p>
      <audio controls src="../../assets/audio/track-01.mp3"></audio>
    </div>

  </main>

</body>
</html>
```

**注意音频路径 `../../assets/audio/`**：

```
D:\my-site\assets\audio\track-01.mp3
D:\my-site\learning\site\music.html     ← 从这个文件出发

先 ..  → D:\my-site\learning\
再 ..  → D:\my-site\
再 assets/audio/track-01.mp3
```

**两个 `..`。** 这就是第 6 课那个"第一次图片没显示"的同一个问题。

## 五、导航要四个页面统一

你的站点现在有 4 个页面。**每个页面的 `<nav>` 必须一模一样**，只差"当前页"不一样。

现在去 `index.html`、`projects.html`、`notes.html`，把 nav 改成：

```html
<nav class="nav">
  <a href="index.html">首页</a>
  <a href="projects.html">项目</a>
  <a href="music.html">音乐</a>
  <a href="notes.html">笔记</a>
</nav>
```

**三个文件都要改。** 漏一个，从那个页面就点不到音乐页。这是纯手动的重复劳动——也是后面要学"模板"的原因。

## 六、播放器样式

在 `site.css` 末尾加：

```css
/* ---------- 音乐页 ---------- */
.track {
  padding: 20px 24px;
  border: 1px solid #e6e8ec;
  border-radius: 12px;
  background-color: #ffffff;
  margin-bottom: 16px;
}

.track .meta {
  font-size: 13px;
  color: #999999;
  margin-bottom: 12px;
}

audio {
  width: 100%;
}
```

`audio { width: 100% }` 让播放器撑满卡片宽度——默认宽度是固定的 300px，在手机上很难点。

## 八、这一课踩的坑

| 现象 | 原因 |
|---|---|
| 播放器显示了但点播放没声音 | `src` 路径错。F12 → **Network** 面板，找红色的 `track-01.mp3`，看它请求的路径 |
| 播放器完全不显示 | 漏了 `controls` 属性 |
| 音乐页 404 | 文件建错位置，或 nav 里写的文件名和实际不符（大小写敏感！Linux 服务器上 `Music.html` ≠ `music.html`） |
| 音频能播但 Safari 不行 | FLAC 格式。换 MP3 |
| 卡片里的文字挤在一起 | 漏了 `.track` 类，或 `site.css` 没保存 |
