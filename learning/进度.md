## ✅ 第 6 课 JS 入门

两个任务都跑通：

- 暗色模式：`document.body.classList.toggle("dark")`
- 点击计数：`count = count + 1` → `countEl.textContent = count`

**顺手纠正了一个认知**：`querySelector("#counter","#count")` 里第二个参数是被**忽略**的。
`querySelector` 只接受一个选择器，选的是"第一个匹配的元素"。要选多个得用 `querySelectorAll`。

## ✅ 第 7 课 把网站变成真的

四个页面 + 音乐页全部跑通：

- 首页：名字 + 圆形头像（flex `space-between` 推到右端，`object-fit: cover` 防变形）
- 项目页：3 个真项目（C++ 成绩管理、Python MIDI 转调、这个网站）
- 音乐页：`<audio controls>` 能播，1:45
- 笔记页：3 条笔记
- 四页 nav 统一、footer 统一

**踩过的坑**（都有价值）：

1. `<img>` 放进了 `<head>` → 必须在 `<body>`
2. `track-01.mp3.mp3` 双后缀 → Windows 隐藏扩展名导致
3. 无 `class` 的 `<img>` 按原图 720×1162 撑爆卡片
4. `img.avatar` 比 `.avatar` 优先级高，两条规则冲突时前者赢
5. 四个文件改四遍 → 漏改了 `notes.html` 的"音乐"链接
