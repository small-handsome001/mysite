
- 指纹：`SHA256:nxSxR3B2gTxkWhJ+tq1vozIxpuFCTdwzO5Bogbk1Juw`（ED25519）
- GitHub 上标题叫 `a easy trying`
- remote 已改为 `git@github.com:small-handsome001/mysite.git`
- 验证：`ssh -T git@github.com` 返回 `Hi small-handsome001!`，`git push` 4.2 秒无任何密码提示
- `github.com:22` 端口本机可通，**不需要** `ssh.github.com:443` 备用方案

**踩坑记录（重要）**：
第一次生成用了 `ssh-keygen -N '""'`，PowerShell 把两个引号当**字面量**传进去，
私钥密码变成了 `""` 两个字符 → SSH 日志出现诡异组合：
`Server accepts key` 之后紧跟 `Permission denied (publickey)`（服务器认得钥匙，但本机签不了名）。
**判据**：`Server accepts key` + `Permission denied` = 私钥打不开，不是公钥没配对。

**校验习惯**：生成后立刻跑 `ssh-keygen -y -f ~/.ssh/id_ed25519`。
直接打印公钥 = 没密码 ✅；卡住等输入 = 有密码 ❌。
（Windows 上改用 `cmd /c` 传 `-N ""` 才能得到真空字符串。）

### 顺手修掉的真实 bug：手机端导航溢出

用 iframe 摆 320/390/430 三个宽度实测（headless 的 `--window-size` 对媒体查询不可靠，iframe 宽度才是准的），
发现 **390px 下手机会横向滚动，右上角"笔记"被截断**。

原因：`.site-header` 是 `flex` + `justify-content: space-between`，窄屏放不下「名字 + 4 个链接」，
但 flex 不会自己换行。

```css
@media (max-width: 600px) {
  .site-header { flex-direction: column; align-items: flex-start; gap: 8px; }
  .nav a { margin-left: 0; margin-right: 18px; }
  .nav a:last-child { margin-right: 0; }
}
```

**新学的知识点**：媒体查询在 iframe 里按 iframe 宽度生效 —— 这是验证响应式最省事的办法，
不用真的掏手机，也不用装插件。
