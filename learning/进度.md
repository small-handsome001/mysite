**踩坑记录（重要）**：
第一次生成用了 `ssh-keygen -N '""'`，PowerShell 把两个引号当**字面量**传进去，
私钥密码变成了 `""` 两个字符 → SSH 日志出现诡异组合：
`Server accepts key` 之后紧跟 `Permission denied (publickey)`（服务器认得钥匙，但本机签不了名）。
**判据**：`Server accepts key` + `Permission denied` = 私钥打不开，不是公钥没配对。

**校验习惯**：生成后立刻跑 `ssh-keygen -y -f ~/.ssh/id_ed25519`。
直接打印公钥 = 没密码 ✅；卡住等输入 = 有密码 ❌。
（Windows 上改用 `cmd /c` 传 `-N ""` 才能得到真空字符串。）

### 顺手修掉的真实 bug：手机端导航溢出


**新学的知识点**：媒体查询在 iframe 里按 iframe 宽度生效 —— 这是验证响应式最省事的办法，

### 这一课踩的四个坑（都值得记）

| 现象 | 原因 | 教训 |
|---|---|---|
| 页面空白，Console 无红字 | `.then` 里只有注释，没写渲染代码 | **请求成功 ≠ 画出来了**：白屏先看 Network 是否 200 |
| `list.map.join("")` 报错 | `map` 是方法，不是数组 | 要 join 的是 map 的**返回值**，先 `const parts = ...` |
| `map` 结果没接住 | 没有变量接收返回值 | 返回值不接就等于扔了 |
| `err is not defined` | 复制失败提示时把 `.catch(function (err) {...})` 的**壳**删了，只剩内容 | **外壳决定"什么时候执行"，内层决定"执行什么"**，抄代码要抄完整结构 |

**平台期提醒**：`.catch(function (err) { ... })` 里，`err` 只在这个函数的作用域里存在。
把里面的语句搬到外面，`err` 就不存在了 —— 这是 JS 作用域的第一个真实教训。
