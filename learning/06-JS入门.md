# 第 6 课 · JavaScript 入门

HTML 是结构，CSS 是样式，**JS 是行为**。从这一课起，网页能"响应点击"。

---

## 一、JS 放在哪

```html
<body>
  ...内容...

  <script src="06-demo.js"></script>
</body>
```

**放在 `</body>` 前面**，不要放 `<head>` 里。

原因：JS 要操作页面上的元素，得先让元素存在。放 head 里，执行时元素还没生成，会报 `null` 错误。

> 想放 head 里也行，但要加 `defer`：`<script src="x.js" defer></script>`。
> `defer` 意思是"等 HTML 解析完再执行"。现在先记"放 body 末尾"最简单。

## 二、变量和数据类型

```js
let count = 0;          // 可以改
const name = "幽林";     // 不能改（常量）

count = count + 1;      // ✅
name = "别的";           // ❌ 报错：Assignment to constant variable
```

| | Python | JS |
|---|---|---|
| 变量 | `x = 1` | `let x = 1;` |
| 常量 | 没有真正常量 | `const X = 1;` |
| 字符串 | `"abc"` / `'abc'` | `"abc"` / `'abc'` / `` `abc` `` |
| 分号 | 不需要 | **建议都写** |

**规则**：能用 `const` 就用 `const`，需要改才用 `let`。**永远别用 `var`**（老写法，有坑）。

**注意大括号和分号**——JS 和 CSS 一样用 `{}` 包代码块，但句末要 `;`。

## 三、函数

```js
function greet(name) {
  return "你好，" + name;
}

console.log(greet("幽林"));   // 控制台输出：你好，幽林
```

和 Python 的 `def` 一样，只是关键字换成 `function`，参数不用写类型。

**`console.log()` 是你的 print。** 按 F12 → Console 就能看到输出。
**调试第一步永远是 console.log**，看变量到底是不是你以为的值。

## 四、DOM：用 JS 操作页面

**DOM = 浏览器把 HTML 解析成的那棵树。** JS 通过它来读写页面。

```js
// 选中一个元素（CSS 选择器怎么写，这里就怎么写）
const title = document.querySelector("h1");
const card  = document.querySelector(".card");
const all   = document.querySelectorAll(".card");   // 所有匹配的

// 改内容
title.textContent = "新标题";

// 改属性
const img = document.querySelector("img");
img.src = "assets/photo.jpg";

// 改样式（通过加/删 class，不要直接改 style）
title.classList.add("highlight");
title.classList.remove("highlight");
title.classList.toggle("dark");     // 有就删，没有就加 ← 最常用
```

**`querySelector(".card")`** 和 CSS 里写 `.card { }` 是同一个选择器语法。这是你第 3 课已经会的东西。

> 为什么用 `classList` 而不是直接改 `style`？
> 因为样式该写在 CSS 里。JS 只负责"切换状态"，`.dark` 长什么样交给 CSS 定义。
> **这就是第 3 课"结构/样式/行为分离"的延续。**

## 五、事件：点击之后发生什么

```js
const btn = document.querySelector("#toggle");

btn.addEventListener("click", function () {
  document.body.classList.toggle("dark");
  console.log("点了");
});
```

拆开看：

| 部分 | 意思 |
|---|---|
| `addEventListener` | "监听一个事件" |
| `"click"` | 事件类型：点击。还有 `"input"`、`"submit"`、`"keydown"` 等 |
| `function () { ... }` | 事件发生时执行的**回调函数** |

**回调函数和 Python 的"把函数当参数传"是一回事：**

```python
button.on_click(lambda: print("点了"))
```

## 六、动手：暗色模式开关

打开 [06-js.html](06-js.html)，结构已经写好了：

- 一个按钮 `#toggle`，文字"切换暗色"
- 一个计数器按钮 `#counter`，一个显示数字的 `#count`

打开 [06-demo.js](06-demo.js)，完成 3 个任务：

| 任务 | 做什么 |
|---|---|
| 1 | 点 `#toggle`，给 `body` 加/删 `dark` 类 |
| 2 | 点 `#counter`，把 `count` 加 1，并显示到页面上 |
| 3 | 用 `console.log` 打印每次点击后的值，F12 里验证 |

### 完整代码框架（自己填）

```js
// 任务 1
const toggleBtn = document.querySelector("#toggle");
toggleBtn.addEventListener("click", function () {
  document.body.classList.toggle("dark");
});

// 任务 2
let count = 0;
const counterBtn = document.querySelector("#counter");
const countEl = document.querySelector("#count");

counterBtn.addEventListener("click", function () {
  count = count + 1;
  countEl.textContent = count;
});
```

CSS 里已经有 `.dark` 的样式（在 `06-demo.css`），你不用写。

## 七、这一课的坑

| 现象 | 原因 |
|---|---|
| `Cannot read properties of null` | `querySelector` 没找到元素。**选择器拼错，或 script 放在 head 里元素还没生成** |
| 点了没反应 | `addEventListener` 拼错 / 事件名不是 `"click"` / 括号没配对 |
| 变量一直不变 | 把 `let count` 写进了函数里，每次点击都重新初始化。**变量要写在函数外面** |
| `console.log` 没输出 | 看的是 Console 面板吗？还是 Elements？ |
| 中文引号 | 和 HTML/CSS 一样，JS 也必须用英文 `"` `'` |

**第一条最多。** 记住：报 `null` 就是"没找到元素"，先去 F12 → Console 看它说的行号，再检查选择器。
