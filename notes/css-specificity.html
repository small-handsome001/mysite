写了 width: 120px 却不生效：CSS 优先级的第一课

2026-10-13 · CSS

同一个文件里，我明明写了 width: 120px，浏览器就是不认。 折腾了二十分钟才发现，是另一条我以为不相关的规则赢了我。

现象

我的样式表里同时有这两条：

.avatar {
  width: 120px;
  height: 120px;
  border-radius: 50%;
}

img.avatar {
  width: 200px;
  height: 200px;
  border-radius: 20%;
}

HTML 是 <img class="avatar" src="..." />。

我盯着 .avatar 那一条看，心想「明明写的 120px」。实际渲染出来是 200px。

原因：不是顺序，是权重

CSS 比较「谁的规则更具体」，不是「谁写在后面」。你这张图有 class，也是 img 标签，所以：

选择器标签classid合计
.avatar0100-1-0
img.avatar1101-1-0

img.avatar 多了一个标签，所以它更具体、权重更高，赢。 跟它们谁先写、谁后写没有关系（权重相同时才比先后）。

这也解释了我之前的一个困惑：为什么 CSS 文件里写在前面的规则有时候会覆盖后面的。 因为覆盖看的是权重，顺序只在打平时才起作用。

怎么一眼看出来

F12 → Elements → 点中元素 → 右侧 Styles 面板：

img.avatar {          ← 生效的，正常显示
  width: 200px;
}

.avatar {             ← 被划掉的（划一条横线）
  width: 120px;       ← 说明它输给了别人
}

被划掉的那条就是输掉的规则。 这个划线功能我一开始以为只是装饰，其实它直接告诉你「谁赢了」。

解决办法

有两条路，我选了第一条：

1. 统一选择器（推荐）

这两条规则本来就是我不同时候写的，重复了。 删掉 img.avatar，只留 .avatar，世界清净。

2. 用 !important（不推荐）

.avatar {
  width: 120px !important;   /* 能生效，但它会破坏权重逻辑 */
}

!important 相当于「我说了算，别管权重」。 它确实能救急，但下次你想覆盖它，就得再加一个 !important。 用一个换一个，最后整个样式表谁也说不出哪条在生效。

我现在的习惯

同一个元素在样式表里只应该有一条主规则。 两条规则管同一个东西，八成是我在某个时刻忘了之前写过。

遇到「样式没生效」，先别改代码，先按 F12 看那条划线—— 它比我的记忆可靠。
